# Determiners — Belirleyiciler

Determiner'lar bir isim öbeğinin başına gelen ve o ismin ne ölçüde belirlenmiş ya da belirli olduğunu gösteren kelimelerdir. İsmin nasıl anlaşılacağını — hangi şey, kimin şeyi, ne kadar — çerçevelerler.

---

## Yapı / Structure

### Determiner Türleri (7 Ana Tür)

| Tür | Örnekler | Açıklama |
|---|---|---|
| **1. Makaleler (Articles)** | a / an / the / (sıfır makale) | En temel belirleyiciler |
| **2. Gösterme sıfatları (Demonstratives)** | this / that / these / those | Yakın/uzak, tekil/çoğul |
| **3. İyelik sıfatları (Possessives)** | my / your / his / her / its / our / their | Kime ait olduğu |
| **4. Niceleyiciler (Quantifiers)** | some / any / no / each / every / either / neither | Miktar/sayı |
| **5. Sayılar (Numbers)** | one / two / first / second | Sıralı veya temel sayılar |
| **6. Dağıtım sözcükleri (Distributives)** | each / every / either / neither / both / all / half | Grup veya birey odaklı |
| **7. Fark sözcükleri (Difference words)** | other / another / else | Farklılık belirtir |

---

### Üç Konum: Predeterminer / Central / Postdeterminer

#### PREDETERMINER'LAR (Merkezi belirleyiciden ÖNCE gelir)
Yalnızca şu sözcükler predeterminer olabilir:
- **all, both, half** → "**all** the students" / "**both** my children" / "**half** a bottle"
- **double, twice, three times** → "**twice** the price" / "**double** his salary"
- **such (a)** → "**such** a pity" / "**such** problems"
- **what (a)** → "**What** a day!" / "**What** an idea!"

#### MERKEZI BELIRLEYICILER (Aynı anda yalnızca BİR TANE)
Makaleler, demonstratives, possessives, quantifiers ve sorular (which/what/whose) central determiner'dır.

> KRITIK KURAL: İki central determiner YAN YANA GELEMEZ:
> - ❌ "the my book" / ❌ "a this car" / ❌ "some the water"
> - ✓ "my book" / ✓ "this car" / ✓ "the water"

#### POSTDETERMINER'LAR (Central determiner'dan SONRA gelir)
- Sıra sayıları (ordinals): first, second, last, next
- Temel sayılar (cardinals): one, two, three
- Bazı niceleyiciler: many, few, several
- Örnekler: "the **many** advantages" / "his **few** friends" / "my **other** car" / "the **first** two students"

## Kullanım Alanları / Uses

### EACH vs EVERY

| | EACH | EVERY |
|---|---|---|
| Vurgu | Bireysel (tek tek) | Grubun tamamı |
| Minimum eleman | 2+ | Genellikle 3+ |
| Periyodik ifadeler | ❌ | ✓ "every other day" / "every few minutes" |
| Olağan frekans | ❌ | ✓ "every morning" |

### ALL vs WHOLE

| | ALL | WHOLE |
|---|---|---|
| Kullanım | all (the) + çoğul/sayılamayan | the whole + tekil sayılabilen |
| Örnek | "all (the) students" / "all (the) milk" | "the whole class" / "the whole bottle" |
| Süre vurgusu | "all day" → ne kadar sürdü | "the whole day" → hiç ara vermeden tamamlandı |

### ANOTHER vs OTHER vs ELSE

| Sözcük | Kullanım | Örnek |
|---|---|---|
| **another** | bir tane daha (tekil, sayılabilen) | "Can I have **another** coffee?" |
| **other** | farklı, geri kalan (çoğul veya uncountable) | "Do you have **other** options?" |
| **others** (zamir) | diğerleri (bağımsız) | "Some passed; **others** failed." |
| **else** | başka (belirsiz zamir + soru sözcükleriyle) | "something **else**" / "nobody **else**" / "where **else**?" |

### SUCH + a/an + sıfat + isim SIRASI
- "**such a** beautiful day" ✓
- "**such a** beautiful day" değil "such beautiful a day" ❌
- Mukayese: "**What a** lovely day!" — what ile aynı yapı

## Edge Cases & Yaygın Hatalar

### "Iki Central Determiner Yan Yana Gelemez" Kuralı
Bu kural son derece önemlidir:
- ❌ "the my friend" → ✓ "my friend"
- ❌ "a some water" → ✓ "some water"
- ❌ "every the student" → ✓ "every student"

### WHICH vs WHAT (Determiner olarak)
- **which** → sınırlı seçenekten belirli bir şey seçilir: "**Which** book do you want?" (belirli seçenekler arasından)
- **what** → sınırsız/açık soru: "**What** book are you reading?"

### BOTH / EITHER / NEITHER (İkili gruplar için)
- **both** = ikisi de (olumlu): "**Both** students passed."
- **either** = ikisinden biri (seçim): "You can use **either** hand."
- **neither** = ikisi de değil (olumsuz): "**Neither** student failed." (ya da "**Neither** of them failed.")
- either/neither → tekil fiil (formal); çoğul fiil de kabul görür (informal)

### HALF Kullanımı
- half + a/an + isim: "**half** an hour" / "**half** a bottle"
- half + the + isim: "**half** the class" / "**half** the time"
- half of + zamir: "**half of** them"

## Örnek Cümleler / Examples

1. "**All** the students passed the exam." → Predeterminer + central.
2. "**Both** my parents work in healthcare." → Predeterminer + possessive.
3. "**Half** a loaf is better than none." → Predeterminer.
4. "**Such** a shame you couldn't come!" → Predeterminer, duygu ifadesi.
5. "**What** a brilliant idea!" → Predeterminer ünlem.
6. "I've read **the** **first** **two** chapters." → Central + ordinal + cardinal postdeterminer.
7. "His **few** friends were always supportive." → Possessive + postdeterminer.
8. "The **many** benefits of exercise are well documented." → Central + postdeterminer.
9. "**Each** child received a different gift." → Individual focus.
10. "**Every** morning she goes for a run." → Group/habitual.
11. "She trains **every other** day." → Periyodik — sadece "every" çalışır.
12. "We need **another** volunteer." → One more, singular.
13. "Do you have **other** sizes available?" → Different options.
14. "Some people loved it; **others** hated it." → Pronoun use.
15. "Is there **somewhere else** we can meet?" → else + question word.
16. "It was **such** a long journey!" → Predeterminer with a/an.
17. "**Neither** option is ideal." → Negative dual — tekil fiil.
18. "**Either** solution would work." → Choice between two.
19. "I'll take **the** **last** ticket." → Central + postdeterminer.
20. "**Twice** the effort for **half** the reward." → Double predeterminer use.
