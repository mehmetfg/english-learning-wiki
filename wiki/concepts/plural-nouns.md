# Plural Nouns — Çoğul İsimler

İngilizce'de çoğul yapılar, düzenli (regular) ve düzensiz (irregular) olmak üzere ikiye ayrılır. Düzenli çoğullar belirli yazım kurallarına göre oluşturulurken, düzensiz çoğullar ezberlenmelidir. Bunların yanı sıra bazı isimler hem tekil hem çoğul için aynı formu kullanır, bazıları ise yalnızca çoğul formda bulunur.

---

## Yapı / Structure

### Düzenli Çoğullar (Regular Plurals)

**Temel kural — çoğu isme + -s:**
```
book → books       table → tables
dog → dogs         car → cars
student → students house → houses
```

**-s, -ss, -sh, -ch, -x, -z ile bitenler → + -es:**
```
bus → buses        class → classes
dish → dishes      church → churches
box → boxes        buzz → buzzes
match → matches    watch → watches
```
> Söyleyişte bir hece ekler: /ɪz/ sesi

**Ünsüz + -y ile bitenler → -y düşer, + -ies:**
```
city → cities      baby → babies
party → parties    lady → ladies
country → countries  story → stories
```

**Ünlü + -y ile bitenler → sadece + -s:**
```
day → days         boy → boys
key → keys         toy → toys
monkey → monkeys   valley → valleys
```
> Ünlü + y'de y düşmez!

**-f / -fe ile bitenler → -ves (çoğu):**
```
leaf → leaves      knife → knives
wife → wives       wolf → wolves
shelf → shelves    half → halves
life → lives       self → selves
thief → thieves    loaf → loaves
```
**Ama** (değişmeyenler — sadece + s):
```
roof → roofs       proof → proofs
belief → beliefs   cliff → cliffs
chef → chefs       chief → chiefs
```
> Kural değil, ezber gerektirir!

**-o ile bitenler — iki grup:**

+ -es alan yaygın olanlar:
```
tomato → tomatoes  potato → potatoes
hero → heroes      echo → echoes
volcano → volcanoes  torpedo → torpedoes
```

+ -s alan olanlar (genellikle kısa/yabancı kökenli):
```
photo → photos     radio → radios
piano → pianos     studio → studios
video → videos     memo → memos
logo → logos       kilo → kilos
```
> Bu grupta kesin kural yoktur; yaygın olanları ezberlemek gerekir.

---

### Latince/Yunanca Kökenli Düzensiz Çoğullar

**-is → -es:**
```
basis → bases          crisis → crises
analysis → analyses    thesis → theses
axis → axes            diagnosis → diagnoses
hypothesis → hypotheses  parenthesis → parentheses
```

**-on → -a:**
```
criterion → criteria       phenomenon → phenomena
```
> "criteria is" ve "phenomena is" yaygın ama prescriptively (kurallı dil bilgisi açısından) yanlış.

**-um → -a:**
```
datum → data               medium → media
curriculum → curricula     memorandum → memoranda
bacterium → bacteria       stratum → strata
```
> "curricula" yerine "curriculums" da giderek kabul görmektedir.

**-us → -i (Latince):**
```
cactus → cacti (veya cactuses)
fungus → fungi
nucleus → nuclei
stimulus → stimuli
syllabus → syllabi (veya syllabuses)
radius → radii
focus → foci (veya focuses)
```

**-ix / -ex → -ices:**
```
appendix → appendices (veya appendixes)
index → indices (veya indexes)
matrix → matrices
vertex → vertices
```
> Akademik/bilimsel bağlamda Latince form; günlük dilde İngilizce form tercih edilir.

---

### Tamamen Düzensiz Çoğullar (Irregular Plurals)

Tamamen farklı form alan isimler — ezberlenmelidir:

```
man → men              woman → women
child → children       mouse → mice
louse → lice           goose → geese
tooth → teeth          foot → feet
ox → oxen              person → people (veya persons — resmi/hukuki)
```

---

### Sıfır Çoğul (Zero Plural — Aynı Form)

Tekil ve çoğul aynıdır:

```
sheep → sheep          fish → fish (veya fishes — farklı türler için)
deer → deer            species → species
aircraft → aircraft    series → series
means → means          headquarters → headquarters
```

```
"One fish, two fish." (aynı tür)
"The fishes of the Amazon include many species." (farklı türler)
"There are three sheep in the field."
"The aircraft was grounded." / "Several aircraft were grounded."
```

---

### Yalnızca Çoğul Olan İsimler (Pluralia Tantum)

Bu isimler hiçbir zaman tekil formda kullanılmaz:

```
scissors     glasses/spectacles    trousers
jeans        shorts                tights
leggings     pliers                tweezers
scales (terazi)  goods             clothes
wages        thanks                regards
customs (gümrük)
```

Sayılabilir hale getirmek için "a pair of" kullanılır:
```
a pair of scissors / two pairs of trousers
a pair of glasses / three pairs of jeans
```

---

### Bileşik İsimlerin Çoğulu (Compound Nouns)

**İsim + isim bileşikleri → ikinci kelime çoğul alır:**
```
bookshelf → bookshelves
toothbrush → toothbrushes
bedroom → bedrooms
suitcase → suitcases
```

**Baş isim + edat/sıfat bileşikleri → baş isim çoğul alır:**
```
mother-in-law → mothers-in-law
passer-by → passers-by
man-of-war → men-of-war
editor-in-chief → editors-in-chief
```
> Bileşiğin anlamsal merkezi olan kelime çoğul alır.

**Fiil + isim bileşikleri:**
```
forget-me-not → forget-me-nots (kural dışı, sonuncu çoğul alır)
grown-up → grown-ups
stand-by → stand-bys
```

## Kullanım Alanları / Uses

### Çoğul Fiil Uyumu

Çoğul isimler çoğul fiil alır:
```
The books are on the table.
Several students have arrived.
Many problems remain unsolved.
```

Kolektif isimler (AmE tekil, BrE ikisi de mümkün):
```
AmE: The team is playing well.
BrE: The team is/are playing well.
```

---

## Edge Cases & Yaygın Hatalar

**"Data is/are" — tartışmalı kullanım:**
```
Data is collected from multiple sources. (giderek yaygınlaşan, özellikle teknoloji alanında)
The data are being analysed. (geleneksel/akademik kullanım — hâlâ tercih edilir)
```
> "Data" Latin'de "datum"un çoğuludur; ama İngilizce'de giderek tekil sayılamaz isim gibi kullanılıyor.

**"Media" — benzer durum:**
```
Social media is powerful. (modern, yaygın)
The media are responsible for... (geleneksel)
```

**"Criteria is" — hâlâ yanlış:**
```
✗ This criteria is wrong.
✓ This criterion is wrong.
✓ These criteria are wrong.
```

**"Agenda" — tamamen İngilizleşmiş:**
```
✓ The agenda is ready. (tekil — artık Latin çoğul olarak değil İngilizce tekil olarak kullanılır)
✓ We have several agendas for the meeting. (İngilizce çoğul da mümkün)
```

**"Antenna" — bağlama göre:**
```
antennae → biyolojide (böcek antenleri)
antennas → radyo/teknoloji (anten)
```

**Özel isimlerin çoğulu:**
```
the Smiths (Smith ailesi — 's eklenmez)
the Joneses (Jones ailesi — es eklenir, Jones' değil!)
two Toms (iki Tom adında biri)
the 1990s (on yıllar — apostrof olmadan)
```

**Rakam + isim sıfat tamlaması → tekil kalır:**
```
a five-year plan (beş yıllık plan — "years" değil)
a two-hour meeting
a ten-dollar bill
```

**"Staff" ve "staffs":**
```
The staff is/are helpful. (bir kuruluşun personeli)
The staffs of both companies... (iki ayrı kuruluşun personelleri — farklı organizasyonlar)
```

**Sayı + çoğul kelime:**
```
✓ five hundred students (hundred, thousand, million → çoğul almaz sayıdan sonra)
✓ hundreds of students (sayı belirsizse çoğul alır)
✓ two million people / millions of people
```

## Örnek Cümleler / Examples

1. "The **children** ran into the **leaves**." — düzensiz + -ves çoğul
2. "She has three **knives** and two **forks**." — -fe → -ves
3. "The **criteria** for admission **are** clearly stated." — Latince çoğul + çoğul fiil
4. "Several **phenomena** were observed during the experiment." — phenomenon → phenomena
5. "I need a new pair of **glasses**." — pluralia tantum
6. "The **data** suggest a clear trend." (akademik) / "The data suggests..." (modern)
7. "Her **mothers-in-law** both attended the wedding." — bileşik çoğul
8. "Two **sheep** and a **deer** crossed the road." — sıfır çoğul
9. "**Fungi** can be both harmful and beneficial." — -us → -i
10. "The **theses** submitted this year were exceptional." — -is → -es
11. "He caught five **fish** in the morning." (aynı tür) vs. "The **fishes** of this lake include trout and perch." (farklı türler)
12. "The **analyses** confirm our hypothesis." — analysis → analyses
