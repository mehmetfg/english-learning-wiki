# Word Formation (Kelime Türetme)

Bir kelimeyi öğrenmek yerine onun **ailesini** öğrenmek; prefix + root + suffix sistemini anlamak sözcük dağarcığını 3-5 kat büyütür.

> **Temel fikir:** `pre` + `dict` + `able` = predictable  
> → predict (tahmin etmek) → prediction → predictable → unpredictable → unpredictably

---

## 1. Prefix — Ön Ekler

Kelime başına gelerek anlam değiştirir. Kelime türünü **değiştirmez**.

### 1a. Olumsuzluk Prefix'leri

| Prefix | Anlam | Örnekler |
|--------|-------|---------|
| **un-** | not / reverse action | unhappy, undo, unlock, unfair, unusual |
| **in-** | not | incorrect, invisible, inactive, informal |
| **im-** | not (b/m/p'den önce) | impossible, immature, impolite, imbalance |
| **il-** | not (l'den önce) | illegal, illogical, illiterate, illegible |
| **ir-** | not (r'den önce) | irregular, irrational, irrelevant, irresponsible |
| **dis-** | not / opposite | disagree, dislike, dishonest, disappear |
| **non-** | not / without | non-fiction, non-stop, non-toxic, nonsense |
| **mis-** | wrongly / badly | misunderstand, mistake, mislead, misuse |

> **Kural:** `im-/il-/ir-` aslında hepsi `in-`tir; sesletim kolaylığı için değişir.  
> in + possible → impossible (iki dudak sesi: m kullanımı daha kolay)

### 1b. Zaman ve Yer Prefix'leri

| Prefix | Anlam | Örnekler |
|--------|-------|---------|
| **pre-** | before / önce | preview, prevent, predict, prepare, prehistoric |

| **over-** | too much / above | overwork, overlook, overcome, overestimate |

## 2. Suffix — Son Ekler

Kelime sonuna gelerek **kelime türünü değiştirir** — bu yüzden daha güçlü araçtır.

|--------|--------|---------|
| **-tion / -sion** | fiil → isim | information, education, decision, revision |
| **-ment** | fiil → isim | government, development, management, payment |
| **-ness** | sıfat → isim | happiness, darkness, kindness, weakness |
| **-ity / -ty** | sıfat → isim | ability, creativity, reality, loyalty, safety |
| **-er / -or** | fiil → kişi | teacher, doctor, director, actor, manager |
| **-ist** | isim/sıfat → kişi | journalist, scientist, artist, pianist, specialist |

| **-age** | isim → isim | package, village, language, passage, storage |
| **-ship** | isim → durum | friendship, leadership, membership, relationship |
| **-hood** | isim → durum | childhood, neighbourhood, adulthood |

### 2c. Fiil Yapan Suffix'ler

| Suffix | Kaynak | Örnekler |
|--------|--------|---------|
| **-ize / -ise** | isim/sıfat → fiil | organize, realize, modernize, criticize, recognize |
| **-ify / -fy** | isim/sıfat → fiil | simplify, justify, identify, qualify, clarify |
| **-en** | sıfat → fiil | strengthen, widen, deepen, shorten, brighten |
| **-ate** | isim → fiil | communicate, calculate, evaluate, generate |

### 2d. Zarf Yapan Suffix

| Suffix | Kaynak | Örnekler |
|--------|--------|---------|
| **-ly** | sıfat → zarf | quickly, carefully, finally, seriously, completely |

> **Dikkat:** `-ly` ile biten her kelime zarf değildir: friendly, lovely, likely (sıfat)

## 6. Kelime Öğrenme İpuçları

**Latin/Yunanca köklerin tanınması:**
- `dict` görünce → söylemek/yazmak ilişkisi
- `-tion` görünce → isim (fiilden türemeli)
- `un-` + sıfat → olumsuzluk hemen anlaşılır

**Tahmin stratejisi:**
1. Prefix'i bul → anlam yönünü belirler
2. Köke bak → çekirdek anlam
3. Suffix'e bak → kelime türü anlaşılır

> Örnek: **uncontrollable**  
> `un-` (olumsuz) + `control` (kontrol etmek) + `-able` (yapılabilir)  
> = "kontrol edilemez"

**Sık yapılan hatalar:**
- `-able` vs `-ible`: Genellikle `-able` ile biten kelimeler fiilden, `-ible` olanlar Latince kökten gelir (visible, possible, responsible)
- `in-` her zaman olumsuz değil: inhabit (içinde yaşamak), inspire, include
- `re-` her zaman "tekrar" değil: require, remain, rely
