# Quantifiers — Niceleyiciler

Quantifier'lar bir ismin miktarını ya da sayısını belirten kelimelerdir. Sayılabilen (countable) isimlerle, sayılamayan (uncountable) isimlerle veya her ikisiyle de kullanılabilirler.

---

## Yapı / Structure

### Yalnızca Sayılabilen İsimlerle (Countable Only)

| Quantifier | Anlam / Not |
|---|---|
| **many** | çok sayıda (soru ve olumsuzda daha doğal; olumlu cümlede formal) |
| **a few** | birkaç tane — YETERLİ, OLUMLU çağrışım |
| **few** | çok az — NEREDEYSE YOK, OLUMSUZ çağrışım |
| **several** | birkaç (genellikle 3–7 arası) |
| **a couple of** | iki ya da üç |
| **each / every** | her biri + tekil isim |
| **another** | bir tane daha / farklı bir |
| **both / either / neither** | ikisi / ikisinden biri / ikisi de değil (sadece 2 için) |

> KRITIK ÇIFT: **"a few"** = bazı, yeterli (pozitif) vs **"few"** = neredeyse hiç (negatif)
> - "She has **a few** friends." → Yalnız değil, arkadaşları var.
> - "She has **few** friends." → Hemen hemen hiç arkadaşı yok, yalnız.

### Yalnızca Sayılamayan İsimlerle (Uncountable Only)

| Quantifier | Anlam / Not |
|---|---|
| **much** | çok (soru/olumsuzda daha doğal; olumlu cümlede formal) |
| **a little** | biraz — YETERLİ, OLUMLU çağrışım |
| **little** | çok az — NEREDEYSE YOK, OLUMSUZ çağrışım |
| **a great deal of** | büyük miktarda (formal) |

> KRITIK ÇIFT: **"a little money"** = biraz param var (pozitif) vs **"little money"** = param yok denecek kadar az (negatif/sorun)

### Her İkisiyle de Kullanılanlar (Both Countable & Uncountable)

| Quantifier | Örnek |
|---|---|
| some / any / no | some books / some water |
| a lot of / lots of | a lot of people / a lot of time |
| plenty of | plenty of options / plenty of space |
| enough | enough chairs / enough money |
| more / most | more ideas / more information |
| all / none of | all students / none of the water |
| such | such a mess / such problems |

## Kullanım Alanları / Uses

### SOME vs ANY

| Durum | Kullanım | Örnek |
|---|---|---|
| Olumlu cümle | **some** | "I have **some** milk." |
| Soru ve olumsuz | **any** | "Do you have **any** milk?" / "I don't have **any**." |
| Teklif (evet bekleniyor) | **some** | "Would you like **some** tea?" |
| İstek (evet bekleniyor) | **some** | "Can I have **some** water?" |
| Koşul cümlesi | **any** | "If you have **any** problems, call me." |
| Olumlu + "farketmez hangisi" | **any** | "Take **any** book you like." |

### MUCH / MANY Kullanımı

- **Formal/yazı dilinde** olumlu cümlede kabul edilir:
  - "**Much** work remains." / "**Many** problems exist."
- **Günlük konuşmada** olumlu cümlede **a lot of** tercih edilir:
  - "There's **a lot of** work." / "There are **a lot of** problems."

### EACH vs EVERY

| | EACH | EVERY |
|---|---|---|
| Odak | Bireysel (tek tek) | Grup (hepsi birden) |
| Minimum sayı | 2+ | Genellikle 3+ |
| Özel kullanım | — | "every other day" / "every few minutes" |
| Zorunlu | tekil isim | tekil isim |

- "**Each** student received a certificate." → Her bir öğrenci ayrı ayrı.
- "**Every** student must pass the exam." → Tüm öğrenciler grup olarak.

### A NUMBER OF vs THE NUMBER OF

| İfade | Fiil | Anlam |
|---|---|---|
| **A number of** + çoğul isim | Çoğul fiil | "A number of students **are** absent." |
| **The number of** + çoğul isim | Tekil fiil | "The number of students **is** increasing." |

## Edge Cases & Yaygın Hatalar

### FEWER vs LESS
- **fewer** = sayılabilen isimler (prescriptive/formal kural):
  - "**Fewer** people attended than expected."
  - "**Fewer** mistakes, please."
- **less** = sayılamayan isimler:
  - "I have **less** time today."
  - "**Less** money was spent."
- NOT: "less people" → gayri resmi kullanımda yaygın ama formal metinlerde "fewer people" tercih edilir.

### NONE OF
- Hem tekil hem çoğul fiil kabul edilir:
  - "**None of** them **is** acceptable." (formal)
  - "**None of** them **are** acceptable." (informal — yaygın)

### Predeterminer Olarak ALL / BOTH / HALF
Belirleyiciden (the, my, vb.) ÖNCE gelirler:
- "**all** the students" / "**both** my children" / "**half** a bottle" / "**half** the price"
- "**all** day" → süreye vurgu; "the **whole** day" → tamlığa vurgu

### A FEW / FEW — SIFAT OLARAK
- Her ikisi de sıfat işlevi görür ama çağrışım tamamen zıttır.
- Çeviri tuzağı: Türkçe'de ikisi de "birkaç" gibi görünebilir. İngilizcede anlam farkı kritiktir.

## Örnek Cümleler / Examples

1. "**Many** students failed the exam, but **a few** managed to pass." → Çoğu başarısız oldu, ama birkaçı geçti (umut var).
2. "**Few** students attended the lecture." → Çok az öğrenci geldi (kötü haber).
3. "She earns **a little** money from freelancing." → Biraz kazanıyor (yeterli, sorun yok).
4. "There's **little** hope of recovery." → Neredeyse hiç umut yok.
5. "Would you like **some** coffee?" → Teklif — evet bekleniyor.
6. "Is there **any** coffee left?" → Gerçek soru.
7. "Take **any** seat you like." → Fark etmez hangisi.
8. "**Each** team member must sign the form." → Her üye tek tek imzalamalı.
9. "**Every** player needs a uniform." → Tüm oyuncular grupta.
10. "She goes jogging **every other** day." → Gün aşırı — sadece "every" çalışır, "each other day" ❌
11. "**A number of** complaints **have** been received." → Çoğul fiil.
12. "**The number of** complaints **has** increased." → Tekil fiil.
13. "**Fewer** calories, **less** fat — that's the goal." → fewer (countable), less (uncountable).
14. "**None of** the options **are** acceptable to me." → İkisi de geçerli.
15. "**Both** my parents are teachers." → Predeterminer.
16. "**All** the money was spent." → Predeterminer, tekil sayılamayan.
17. "She has **plenty of** time before the deadline." → Bol miktarda zaman.
18. "**Much** of what he said was incorrect." → Formal, olumlu.
19. "There was **a great deal of** confusion." → Formal, uncountable.
20. "**Several** issues need to be addressed." → Birkaç (3–7 arası).
