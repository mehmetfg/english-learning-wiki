# Question Tags — Ekli Sorular

Soru ekleri (question tags), bir cümlenin sonuna eklenen kısa soru yapılarıdır. Türkçe'deki "değil mi?", "öyle değil mi?", "değil misin?" gibi ifadelere karşılık gelirler. Kullanım amacı: onay alma, doğrulama arama, konuşmayı sürdürme ya da kibarca bilgi edinme.

---

## Yapı / Structure

**Temel Kural:**

```
Olumlu cümle  + olumsuz ek?     "She's coming, isn't she?"
Olumsuz cümle + olumlu ek?      "She isn't coming, is she?"
```

Ek daima ana cümledeki **yardımcı fiille** eşleşmelidir. Yardımcı fiil yoksa do/does/did kullanılır.

---

## Kullanım Alanları / Uses

### Tam Yardımcı Fiil Tablosu

| Ana Cümle | Soru Eki | Örnek |
|-----------|----------|-------|
| is / am / are | isn't / aren't | "He is coming, **isn't he**?" |
| **I am** | **aren't I?** | "I'm right, **aren't I**?" ← özel kural |
| was / were | wasn't / weren't | "She was here, **wasn't she**?" |
| have / has | haven't / hasn't | "They've finished, **haven't they**?" |
| had | hadn't | "He'd done it, **hadn't he**?" |
| will | won't | "You'll come, **won't you**?" |
| shall | shan't | "We shall see, **shan't we**?" |
| would | wouldn't | "She'd help, **wouldn't she**?" |
| can | can't | "He can swim, **can't he**?" |
| could | couldn't | "You could try, **couldn't you**?" |
| should | shouldn't | "We should leave, **shouldn't we**?" |
| may | mayn't / mightn't (nadiren) | "She may come, **mightn't she**?" (pek kullanılmaz) |
| must | mustn't | "We must hurry, **mustn't we**?" |
| do / does | don't / doesn't | "You like coffee, **don't you**?" |
| did | didn't | "They arrived late, **didn't they**?" |
| used to | didn't (genellikle) | "You used to smoke, **didn't you**?" |
| ought to | shouldn't | "He ought to apologize, **shouldn't he**?" |

## Özel Durumlar / Special Cases

### 1. "I am..." → "aren't I?"
```
"I'm late, aren't I?"     ✓  (standart İngilizcede kabul görülür)
"I'm late, amn't I?"      ✗  (bazı diyalektlerde duyulur, standart değil)
"I'm late, ain't I?"      ✗  (informal/dialectal, standart değil)
```

### 2. Emir Cümleleri (Imperatives) → will / won't / would / can / could
```
"Close the door, will you?"     → nötr, standart
"Close the door, won't you?"    → daha sıcak, ikna edici
"Close the door, would you?"    → kibar, nazik
"Close the door, can you?"      → informal
"Close the door, can't you?"    → sinirli, bıkmış
"Don't make noise, will you?"   → olumsuz emir + olumlu ek
```

### 3. "Let's..." → "shall we?"
```
"Let's go for a walk, shall we?"      ✓
"Let's not argue about this, shall we?" ✓
```

### 4. Olumsuz Sözcükler → Olumlu Ek
Nobody, no one, nothing, nowhere, never, hardly, scarcely, barely, seldom, rarely gibi sözcükler cümleyi anlam olarak olumsuzlaştırır — bu nedenle ek olumlu olur. Zamir için they/it kullanılır.

```
"Nobody called, did they?"          ✓ (nobody → they)
"Nothing happened, did it?"         ✓ (nothing → it)
"No one came to the party, did they?"  ✓
"She never complains, does she?"     ✓
"Hardly anyone noticed, did they?"   ✓
"There's nowhere to go, is there?"   ✓
```

### 5. Someone / Somebody → they
```
"Someone left the door open, didn't they?"   ✓
"Somebody called for you, didn't they?"      ✓
```

### 6. Everything / Something → it
```
"Everything's fine, isn't it?"    ✓
"Something went wrong, didn't it?" ✓
```

### 7. There + be
```
"There's a problem, isn't there?"     ✓
"There were delays, weren't there?"   ✓
"There isn't much time, is there?"    ✓
```

### 8. Must — Zorunluluk vs Çıkarım
- **Zorunluluk:** "We must leave now, **mustn't we**?"
- **Çıkarım:** "She must be tired, **mustn't she**?" ← bu garip gelir; genellikle:
  "She must be tired, **don't you think**?" veya "**surely**?" tercih edilir.

## Tonlama / Intonation

Soru ekinin anlamı tonlamaya göre değişir:

### Alçalan Ton (Falling) — Onay Arama
Konuşmacı cevabı neredeyse biliyor; sadece doğrulama istiyor ya da sosyal bağ kuruyor.
```
"It's a lovely day, isn't it?" ↘  (harika bir gün, değil mi — bana katıl)
"You've been to Paris, haven't you?" ↘  (gittin, değil mi — hatırlıyorum gibi)
```

### Yükselen Ton (Rising) — Gerçek Soru
Konuşmacı gerçekten emin değil; bilgi istiyor.
```
"She WAS here earlier, wasn't she?" ↗  (gerçekten emin değilim)
"He can speak Japanese, can't he?" ↗  (doğrulamak istiyorum)
```

## Aynı Polariteli Ekler (Same Polarity Tags) — İronik/Retorik

Her ikisi de olumlu — sitem, ironi ya da meydan okuma ifade eder.

```
"So you think you're clever, do you?"     → sitem / meydan okuma
"You want MORE money, do you?"            → alaycı
"Oh, you've finally decided to show up, have you?"  → kızgın
```

Bu yapı yükselen tonla söylenir ve genellikle olumsuz bir duygu taşır.

## Edge Cases & Yaygın Hatalar

### 1. "aren't I" — mantık dışı ama doğru
```
"I'm the team leader, aren't I?"    ✓  (standart)
"I'm the team leader, am I not?"    ✓  (çok resmi, edebi)
```

### 2. "must" + deduction — ek için "mustn't" garip kaçar
```
"He must have known the truth, mustn't he?"   ← teknik olarak doğru ama garip
"He must have known the truth, surely?"        ← daha doğal
"He must have known the truth, don't you think?" ← daha doğal
```

### 3. "Let him/her/them" → let + nesne + shall we?
```
"Let him speak, shall we?"     ✓
"Let her try, shall we?"       ✓
```

### 4. Polite request içinde soru eki
```
"You couldn't lend me some money, could you?"
```
Bu olumsuz cümle + olumlu ek formülüne uyar. Nazik ricada olumsuz modal + could you sıklıkla kullanılır.

### 5. "He'd" — had mı would mı?
```
"He'd already left, hadn't he?"   → had (past perfect → hadn't)
"He'd help if he could, wouldn't he?"  → would (koşullu → wouldn't)
```
'd'nin neyi kısalttığına dikkat et — ek ona göre şekillenir.

### 6. "used to" — didn't kullanımı
"Used to" için modal ek yok; "didn't" kullanılır:
```
"She used to live in London, didn't she?"    ✓
"She used to live in London, usedn't she?"   ← eski/resmi BrE, çok nadir
```

### 7. Olumsuz emir + ek
```
"Don't forget your keys, will you?"    ✓
"Don't be late, will you?"             ✓
```

## Örnek Cümleler / Examples

1. "The film starts at eight, **doesn't it**?" — basit geniş, onay arama ↘
2. "You haven't seen my glasses anywhere, **have you**?" — olumsuz → olumlu ek
3. "Let's celebrate with dinner tonight, **shall we**?" — let's teklifi
4. "Nobody told you about the change, **did they**?" — nobody → they
5. "She can speak four languages, **can't she**?" — can eki
6. "It was an incredible performance, **wasn't it**?" — was → wasn't
7. "I'm supposed to be here at nine, **aren't I**?" — "I am" özel durumu
8. "He'd never been abroad before, **had he**?" — had (past perfect olumsuz)
9. "Pass the salt, **will you**?" — emir → will you
10. "Everything went according to plan, **didn't it**?" — everything → it
11. "So you think you can run the department alone, **do you**?" — aynı polarite, meydan okuma
12. "There were no objections, **were there**?" — there + were (olumsuz)
13. "She hardly ever makes mistakes, **does she**?" — hardly → olumlu ek
14. "Don't slam the door, **will you**?" — olumsuz emir
15. "You used to play the piano, **didn't you**?" — used to → didn't
