# Passive Voice

İngilizce edilgen çatı (passive voice) yapısını açıklayan ve örnekleyen araç.

## Dosya

`Artifacts/pasive voice.html`

*(Dosya adında yazım hatası: "pasive" — orijinal dosyaya dokunulmuyor.)*

## Kapsam

Passive Voice kullanım alanları:
- Eylemi yapanı gizleme / önemsiz sayma
- Resmi/akademik yazılarda tercih edilen yapı
- Tüm tense'lerle kullanımı: *is done / was done / has been done / will be done*

## Temel Yapı

```
Active:  [Subject] + verb + [Object]
Passive: [Object] + be (tense) + past participle + (by [Subject])
```

**Örnek:**
- Active: *"The teacher explained the rule."*
- Passive: *"The rule was explained (by the teacher)."*
