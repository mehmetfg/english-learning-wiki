## Hesaplama Formülleri (Claude Code referans)

```
Güç (son 3 oturumun ağırlıklı ort.):
  = (s1*3 + s2*2 + s3*1) / 6
  burada s = (doğru / toplam) * 100

Borç:
  gun_farki = (bugün - son_tarih)  // gün
  zayıflık = 100 - güç_skoru
  borç = (gun_farki * zayıflık) / 100

  Güç bilinmiyorsa zayıflık=100 kabul et.
  Hiç çalışılmamışsa borç = gun_farki * 1 (yani vault başlangıç tarihinden bugüne)
```

## Edge Case (Claude Code dikkat)

- Aynı oturumda hem grammar-first hem text-first çalışılırsa, her ikisi de **ayrı session sayılır** (çift teyit). 1 oturum değil, 2.
- Aynı gün içinde aynı motor 2x çalışırsa, ikinci session **rehearsal** olarak işaretlenir (notlara `rehearsal` ekle) — borç hesabını sıfırlar ama güç skoruna ikinci oturum tam katkı vermez (1.5x değil 1x).
- Eğer 30+ gündür dokunulmamış bir konu varsa `weak-topics.md`'ye eklemek **zorunludur**.
