> 📖 **Konu anlatımı:** [[Plural Nouns]]

**Konu Haritası**

| Kural | Tekil → Çoğul | Örnek |
|---|---|---|
| Genel | + s | book → books |
| -s, -ss, -sh, -ch, -x | + es | box → boxes, watch → watches |
| ünsüz + y | y → ies | city → cities |
| -f / -fe | → ves | knife → knives |
| Düzensiz | değişir | man → men, child → children, foot → feet |
