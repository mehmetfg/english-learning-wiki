If Conditionals — Tüm Tipler

Zero Conditional
Genel Gerçekler & Bilimsel Yasalar
Her zaman doğru olan şeyler için kullanılır. İkisi de Simple Present (Geniş Zaman).
If + Subject + V1 , Subject + V1
If + Geniş Zaman , Geniş Zaman
Geçmiş
→
Şimdi / Her zaman
→
Gelecek
İngilizce
If you heat water, it boils.
Suyu ısıtırsan, kaynar. (Her zaman doğru)
Başka örnek
If it rains, the ground gets wet.
Yağmur yağarsa, zemin ıslanır.
First Conditional
Gerçek & Olası Gelecek
Gerçekleşmesi mümkün olan gelecek durumlar için. If + Simple Present, will + V1.
If + Subject + V1 , Subject + will + V1
If + Geniş Zaman , will + Yalın Fiil
Geçmiş
→
Şimdi (koşul)
→
Gelecek (sonuç)
İngilizce
If I study hard, I will pass the exam.
Çok çalışırsam, sınavı geçeceğim. (Olası)
Başka örnek
If it rains, we will cancel the trip.
Yağmur yağarsa, gezimizi iptal ederiz.
Second Conditional
Hayali / Gerçek Dışı Şimdi veya Gelecek
Şu an gerçekleşmemiş, hayal edilen durumlar için. If + Simple Past, would + V1.
If + Subject + V2 , Subject + would + V1
If + Geçmiş Zaman (anlam: şimdi hayal) , would + Yalın Fiil
Geçmiş
→
Şimdi (gerçek değil)
→
Gelecek
İngilizce
If I were rich, I would travel the world.
Zengin olsaydım, dünyayı gezerdi. (Zengin değilim)
Dikkat: were
If she were here, she would help us.
"was" değil "were" — resmi kullanımda I/he/she ile de "were"
Third Conditional
Geçmişteki Gerçek Dışı Durum
Artık değiştirilemeyen geçmiş olaylar için pişmanlık veya hayal. If + Past Perfect, would have + V3.
If + Subject + had + V3 , Subject + would have + V3
If + Past Perfect , would have + Geçmiş Ortaç
Geçmiş (gerçek değildi)
→
Şimdi
→
Gelecek
İngilizce
If I had studied, I would have passed.
Çalışmış olsaydım, geçecektim. (Çalışmadım, geçemedim)
Başka örnek
If she had called, I would have answered.
Arasa, açacaktım. (Aramadı, açmadım)
Mixed Conditional
Karma: Geçmiş + Şimdi veya Şimdi + Gelecek
İki farklı zamanı birleştirir. En yaygın iki tipi: geçmişin bugüne etkisi & bugünün geçmişe etkisi.
Tip 1 (Geçmiş → Şimdi):
If + had + V3 , would + V1
Tip 2 (Şimdi → Geçmiş):
If + were / V2 , would have + V3
Geçmiş
⟷
Şimdi
⟷
Gelecek
Geçmiş → Şimdi
If I had studied medicine, I would be a doctor now.
Tıp okusaydım, şimdi doktor olurdum. (Okumadım, değilim)
Şimdi → Geçmiş
If I were braver, I would have spoken up.
Daha cesur olsaydım, o zaman konuşurdum. (Cesur değilim)
