İngilizce Conditional (if) cümle türleri - interaktif öğretici

Type 0 — Zero Conditional

Her zaman doğru

Genel gerçekler, bilimsel olgular ve alışkanlıklar için kullanılır. Her ikisi de Simple Present. "If" yerine "when" de kullanılabilir.

IF + Subject + V1  ,  Subject + V1
If you heat water to 100°C, it boils.
Suyu 100°C'ye ısıtırsan kaynar. (Her zaman böyledir)
If it rains, the streets get wet.
Yağmur yağarsa sokaklar ıslanır. (Doğa kanunu)
If I eat too much, I feel sick.
Çok yersem midemi bozuyor. (Kişisel alışkanlık)
Gerçeklik düzeyi: %100 — Bu cümleler evrensel doğrudur, hayal değildir.
████████████ Tam gerçek

Type 1 — First Conditional

Gerçekçi olasılık

Gelecekte gerçekleşmesi mümkün ve muhtemel koşullar için. "Eğer … olursa, … olacak." Şu an için gerçek, gelecek için olası.

IF + Subject + V1 (Simple Present)  ,  Subject + will + V1
If it rains tomorrow, I will stay home.
Yarın yağmur yağarsa evde kalacağım. (Yağabilir!)
If you study hard, you will pass the exam.
Sıkı çalışırsan sınavı geçeceksin.
If she calls, I will answer.
Ararsa açacağım.
Gerçeklik düzeyi: ~%70 — Olabilir, ihtimal var.
████████░░░ Muhtemel

Type 2 — Second Conditional

Hayal / düşük ihtimal

Şu an gerçek olmayan ya da çok düşük ihtimalli durumları hayal etmek için. "Keşke…", "Tutturabilsem…" havası. Türkçedeki "-se/-sa" yapısı gibi.

IF + Subject + V2 (Simple Past)  ,  Subject + would + V1
If I had a million dollars, I would travel the world.
Bir milyon dolarım olsaydı dünyayı gezerdi. (Yok, hayal)
If she spoke English, she would get the job.
İngilizce bilseydi işi alırdı. (Bilmiyor)
If I were you, I would apologize.
Senin yerinde olsam özür dilerdim. (were — hep were!)
⚠ Dikkat: "were" kullanımı — Type 2'de I/he/she/it için was değil were kullanılır. "If I were rich…" (İngilizce gramerinin klasik triki)
Gerçeklik düzeyi: ~%10 — Gerçek değil, hayal.
██░░░░░░░░░ Hayal / varsayım

Type 3 — Third Conditional

Geçmişe pişmanlık

Geçmişte olmayan bir şeyi hayal etmek. "Keşke yapsaydım / yapmayaydım." Artık değiştirilemez — tamamen varsayım.

IF + Subject + had + V3 (Past Perfect)  ,  Subject + would have + V3
If I had studied, I would have passed the exam.
Çalışsaydım sınavı geçmiş olurdum. (Çalışmadım, geçemedim)
If she had left earlier, she wouldn't have missed the bus.
Daha erken çıksaydı otobüsü kaçırmamış olurdu.
If they had known, they would have helped.
Bilselerdi yardım etmiş olurlardı. (Bilmiyorlardı)
Gerçeklik düzeyi: %0 — Geçmişte olmadı, artık mümkün değil.
█░░░░░░░░░░ İmkânsız (geçmiş)

4 Type — Yan Yana Karşılaştırma

Aynı konuyu 4 farklı Type ile nasıl söylersin? Gerçekliğin azaldıkça zaman dilimi geriye gider.

Type 0
If you heat ice, it melts.
Genel gerçek · V1 → V1 · Her zaman olur
Type 1
If it snows tomorrow, I will stay home.
Gerçekçi · V1 → will+V1 · Olabilir
Type 2
If I had a car, I would drive to work.
Hayal · V2 (past) → would+V1 · Gerçek değil
Type 3
If I had taken a taxi, I wouldn't have missed the flight.
Pişmanlık · had+V3 → would have+V3 · Geçti gitti
🔑 Formüller özet
0 IF + V1 → V1
1 IF + V1 → will + V1
2 IF + V2 (past) → would + V1
3 IF + had + V3 → would have + V3
